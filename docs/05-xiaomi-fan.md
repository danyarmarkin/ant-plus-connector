# 05 — Вентилятор Xiaomi

Поддерживается **Xiaomi Mi Smart Standing Fan 2 Lite** (модель `dmaker.fan.1c`). Другие вентиляторы
`dmaker.fan.*` с тем же MIoT-описанием, скорее всего, тоже заработают.

## Вход в аккаунт (по QR, без пароля)

```bash
hr_dashboard/.venv/bin/python xiaomi/login.py
```

1. Скрипт показывает QR-код на <http://127.0.0.1:31415>.
2. В приложении **Mi Home**: Профиль → значок сканера → отсканировать → подтвердить вход.
3. Скрипт обходит все регионы облака (`cn`, `de`, `us`, `ru`, `tw`, `sg`, `in`, `i2`), собирает устройства и
   сохраняет `xiaomi/session.json` (права `600`, в `.gitignore`).

Логин реализован в submodule [`xiaomi_extractor`](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor)
(обращается только к `account.xiaomi.com` и `*.api.io.mi.com`). Пароль не вводится и не хранится.

```bash
hr_dashboard/.venv/bin/python xiaomi/login.py --refresh --server=ru   # перечитать один регион без нового QR
hr_dashboard/.venv/bin/python xiaomi/fan_cloud.py          # состояние вентилятора
hr_dashboard/.venv/bin/python xiaomi/fan_cloud.py on|off|1|2|3
```

## MIoT-свойства `dmaker.fan.1c`

Из <https://miot-spec.org> (`urn:miot-spec-v2:device:fan:0000A005:dmaker-1c:1`), сервис `siid 2`:

| piid | Свойство | Значения |
|---|---|---|
| 1 | on | bool |
| 2 | fan-level | 1, 2, 3 |
| 3 | horizontal-swing | bool |
| 7 | mode | 0 прямой, 1 естественный |
| 10 | off-delay-time | 0–480 мин |
| 11 | alarm (звук) | bool |
| 12 | brightness (индикатор) | bool |

Команды идут через облако: `POST https://<region>.api.io.mi.com/app/miotspec/prop/set` (и `prop/get`)
с RC4-шифрованием параметров, подписанным `ssecurity` из сессии.

## Плавная регулировка

Скорости в процентах у модели нет — только 3 ступени. Плавность делается программно в
`hr_dashboard/server.py`:

1. Пульс сглаживается экспоненциально (постоянная `FAN_HR_SMOOTH_SEC = 10` с).
2. Переводится в непрерывную скорость 1.0–3.0: `FAN_HR_LOW = 90` → 1.0, 120 → 2.0, `FAN_HR_HIGH = 150` → 3.0.
3. Дробная скорость — чередование соседних ступеней в цикле `FAN_CYCLE_SEC = 30` с: 1.6 = 60 % цикла на
   ступени 2 и 40 % на ступени 1. Доли меньше `FAN_MIN_DWELL = 15 %` округляются (без коротких рывков).
   Команды — не чаще раза в `FAN_MIN_CHANGE_SEC = 3` с, обычно 2 за цикл.
4. Нет валидного пульса `FAN_OFF_AFTER_SEC = 30` с — вентилятор выключается.

Режим «плавно по пульсу» включается галочкой на странице и по умолчанию выключен (чтобы при запуске
сервера вентилятор не начал жить своей жизнью). Нажатие ручной кнопки выключает авто-режим.
Если вентилятор пищит на каждое переключение — снимите галочку «звук».

## VPN и регион `ru`

Если на компьютере включён VPN, сервер `ru.api.io.mi.com` может быть недоступен через туннель, а системный
DNS VPN-клиента возвращает «фейковые» адреса из `198.18.0.0/15`. `xiaomi/net.py` решает это только для
запросов к Xiaomi:

- сокеты привязываются к интерфейсу `en0` (`IP_BOUND_IF`, macOS) — трафик идёт мимо туннеля;
- имена `*.mi.com` / `*.xiaomi.com` резолвятся через DNS-сервер этого интерфейса (роутер);
- у запросов таймаут 15 с (регионы `us` и `sg` из некоторых сетей молча не отвечают).

Интерфейс меняется переменной `XIAOMI_IFACE` (пустое значение — отключить обход).

## Без облака

Альтернатива — локальный протокол miIO (UDP 54321, AES c `token` устройства из `session.json`):
работает только в той же сети, зато без облака и VPN-проблем. Подходит для автономного варианта на
ESP32 (идея на будущее: nice!nano принимает ANT+ и отдаёт пульс по UART, ESP32 поднимает Wi-Fi-страницу
и управляет вентилятором по miIO).
