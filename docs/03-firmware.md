# 03 — Прошивка `ant_hrm`

Скетч: [`ant_hrm/ant_hrm.ino`](../ant_hrm/ant_hrm.ino). Плата — «nice!nano (S340 ANT+BLE)».

## Ключ сети ANT+

Устройства ANT+ общаются в сети с 8-байтовым ключом. Garmin публикует его на
<https://developer.garmin.com/ant-program/ant-ant-plus/network-keys/> (ключ «ANT+», 64 бита);
использовать его можно только устройствам, следующим ANT+ Device Profiles. В репозиторий ключ не
кладётся:

```bash
cp ant_hrm/ant_plus_key.h.example ant_hrm/ant_plus_key.h
# заменить нули в ant_plus_key.h на байты ключа
```

Без файла сборка остановится с понятной ошибкой.

## Как устроено

```
Bluefruit.begin()          включает S340 с ANT_LICENSE_KEY, держит USB под SoftDevice
sd_ant_enable()            2 канала, память стека в antStackMem
sd_ant_network_address_set(0, ANT+ key)
sd_ant_lib_config_set(DEVICE_ID | RSSI)   к каждому сообщению добавляются ID отправителя и RSSI

канал 0  HRM: slave, device type 120, RF 57 (2457 МГц), период 8070 (4.06 Гц),
         device number = выбранный или 0 (любой), поиск бесконечный
канал 1  фоновое сканирование (EXT_PARAM_ALWAYS_SEARCH): low-priority поиск без таймаута,
         слышит все ремни поблизости, ни к одному не привязываясь
```

События SoftDevice приходят в прерывание, которым владеет Bluefruit; он отдаёт семафор, `loop()`
просыпается и забирает события `sd_ant_event_get()`.

Нюанс ANT: ремень, который уже ведёт канал 0, **не попадает** в фоновый канал. Поэтому подключённый
ремень добавляется в список датчиков по данным канала 0.

## Что декодируется (ANT+ Heart Rate profile)

Каждая страница — 8 байт. Байты 4–7 одинаковы для всех страниц:

| Байт | Поле |
|---|---|
| 0 | номер страницы (бит 7 — toggle) |
| 4–5 | время последнего удара, 1/1024 с |
| 6 | счётчик ударов (0–255) |
| 7 | вычисленный пульс, уд/мин (0 = невалидно, нет контакта) |

| Страница | Данные |
|---|---|
| 1 | наработка (×2 с) |
| 2 | ID производителя, старшие 16 бит серийного номера |
| 3 | версии железа/ПО, модель |
| 4 | время предыдущего удара → **точный RR-интервал** |
| 7 | батарея: %, напряжение, статус |

RR берётся со страницы 4; если её нет — из разницы времени соседних ударов. Некоторые дешёвые ремни
неправильно ведут счётчик ударов (увеличивают его на каждое сообщение) — на пульс и RR со страницы 4
это не влияет.

## Вывод в Serial (115200)

На каждый принятый пакет (~4 Гц, это частота ремня; быстрее данных нет):

```
[  28.3s] HR  84 bpm | beats  52 | RR  705 ms | ID 12345 | RSSI -54 dBm | batt 80% 2.95V (good) | 4 msg/s, 0 missed
[  45.4s] HR --- (no skin contact) | beats  84 | RR  705 ms | ID 12345 | RSSI -55 dBm | 4 msg/s, 1 missed
[   9.6s] SEARCHING for ANT+ heart rate strap #12345... (put it on / moisten the electrodes)
           info: manufacturer 115, serial 123456789 | model 1, hw 1, sw 1 | operating time 0 h 33 min
```

Раз в 2 секунды — список датчиков (машиночитаемый, его разбирает веб-сервер):

```
SENSORS target=any | 12345 rssi -63 hr 83 age 0.1 * | 23456 rssi -80 hr 0 age 3.2
```

`target` — выбранный ремень или `any`; `*` — к нему сейчас подключён канал 0; `age` — секунд с
последнего пакета. Ремень пропадает из списка через 10 с тишины.

События: `>>> Sensor found, tracking`, `>>> Paired with ANT+ HRM: device #…`,
`>>> Signal lost, searching again...`, `>>> Pairing with strap #…`.

## Команды

Строка, завершённая `\n` (в Serial Monitor — режим «Newline»):

| Команда | Действие |
|---|---|
| `pair 12345` | подключаться только к ремню #12345 |
| `pair any` | подключаться к первому найденному |
| `sensors` | сразу напечатать строку `SENSORS` |

Выбор сохраняется в `InternalFS` (`/hrm_pair.txt`) и восстанавливается после перезагрузки.

Тонкость: SoftDevice пишет флеш только в паузах радио, а сканирующий канал их не оставляет —
запись зависала бы навсегда. Поэтому на время записи оба канала закрываются и потом открываются
заново.

## Светодиод

Синий светодиод (P0.15) вспыхивает на 80 мс с частотой текущего пульса (период `60000 / HR` мс,
пересчитывается на каждом ударе). Нет пульса или ремня — не горит. Фаза не привязана к реальным
ударам: у многих ремней счётчик ударов ненадёжен.

## Настройки в начале скетча

| Константа | По умолчанию | |
|---|---|---|
| `PRINT_RAW_PAGES` | 0 | печатать каждую страницу в hex |
| `MAX_SENSORS` | 8 | размер таблицы датчиков |
| `SENSOR_EXPIRE_MS` | 10000 | когда ремень пропадает из списка |
| `SENSORS_PRINT_MS` | 2000 | период строки `SENSORS` |
